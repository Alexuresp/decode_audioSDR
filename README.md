# SDR-translate

Консольний демон для захоплення аудіо з радіоефіру, розпізнавання мовлення (STT)
та перекладу українською мовою з урахуванням HAM-позивних.

Основний код — у [`decode_audio.py`](decode_audio.py).

## Як працює

Два потоки, сполучені чергами:

```
[Головний потік]                  [Потік обробки]
  sounddevice callback              Groq client (STT + LLM)
        │                           │
        ▼                           ▲
   queue.Queue q  ──VAD──▶   audio_queue  ──▶  STT → LLM → print
```

- `main()` — захоплює аудіо через `sounddevice`, детектує мовлення Silero VAD
  (локально, на CPU), формує фрагменти і кладе їх у `audio_queue`.
- `process_audio_worker()` — забирає фрагмент, пише тимчасовий WAV, відправляє
  в Groq: Whisper для транскрибації, Llama для перекладу; виводить оригінал і
  переклад у термінал з кольоровим виділенням.

## Налаштування

### Аудіо

| Параметр | Значення | Призначення |
|---|---|---|
| `CHANNELS` | `1` | Моно |
| `RATE` | `16000` | Частота дискретизації (вимога Silero/Whisper) |
| `CHUNK` | `512` | Розмір чанку (~32 мс) |

### Groq

| Параметр | Значення |
|---|---|
| `GROQ_STT_MODEL` | `whisper-large-v3` |
| `GROQ_LLM_MODEL` | `llama-3.3-70b-versatile` |

Ключ передається через `GROQ_API_KEY` у файлі `.env`.

### Адаптивний VAD (слабкий сигнал у шумах)

Реалізовано в `main()`:

| Параметр | Значення | Призначення |
|---|---|---|
| `VAD_BASE_THRESHOLD` | `0.5` | Жорстка нижня межа порогу (не опускається нижче) |
| `VAD_NOISE_MARGIN` | `0.15` | Запас порогу над оціненим шумовим полом |
| `VAD_HYSTERESIS` | `0.20` | Різниця між порогом старту та стопу (не рве фрази) |
| `VAD_SMOOTH_ALPHA` | `0.3` | Коефіцієнт згладжування ймовірності (EMA) |
| `VAD_NOISE_ALPHA` | `0.005` | Швидкість адаптації шумового полу |
| `PREROLL_SECONDS` | `0.5` | Буфер аудіо перед початком мовлення |
| `SILENCE_DURATION` | `0.2` | Тривалість тиші для завершення фрагмента |

Похідні величини:

- `SILENCE_CHUNKS = int(RATE / CHUNK * SILENCE_DURATION)`
- `PREROLL_CHUNKS = int(RATE / CHUNK * PREROLL_SECONDS)`

Механізми:

1. **Адаптивний поріг** — `noise_floor` оновлюється EMA тільки у тиші;
   фінальний поріг `= max(VAD_BASE_THRESHOLD, noise_floor + VAD_NOISE_MARGIN)`.
   Підлаштовується під рівень шуму ефіру, тому слабка речь детектиться при низькому SNR.
2. **Гістерезис** — старт вимагає `> start_th`, зупинка — `< start_th - VAD_HYSTERESIS`.
   Прибирає ложні розриви фраз на шумових спалахах.
3. **Pre-roll** — `preroll_buffer` (`collections.deque`) зберігає останні
   `PREROLL_CHUNKS` чанків; при старті запису вони підклеюються на початок фрагмента,
   повертаючи обрізане м'яке початок слова.
4. **Згладжування** — `speech_prob_smooth` (EMA, `VAD_SMOOTH_ALPHA`) фільтрує
   миттєві шумові викиди по чанках 32 мс.

#### Підбір параметрів під ефір

- Ріже кінці фраз → **зменшіть** `VAD_HYSTERESIS`.
- Ловить шум замість мовлення → **збільшіть** `VAD_NOISE_MARGIN`.
- Втрачає початок → **збільшіть** `PREROLL_SECONDS`.
- Дрижить детект → **зменшіть** `VAD_SMOOTH_ALPHA` (більше згладжування).

## Переклад

Промпт для LLM (`process_audio_worker`) містить:

- словник радіоаматорських абеток (латиниця → українська вимова);
- інструкцію додавати латинську абревіатуру позивного в дужках;
- обмеження: виводити **лише** переклад тексту між тегами `<text>` і `</text>`.

Температура генерації — `0.3`.

## Використання

```bash
pip install numpy torch groq sounddevice python-dotenv
cp .env.example .env          # вкажіть GROQ_API_KEY
python decode_audio.py        # вихід — Ctrl+C
```

Вимоги:

- Python 3.10+
- `GROQ_API_KEY` у `.env`
- доступ до мікрофона / віртуального аудіовходу (SDR-приймач через віртуальний кабель)
